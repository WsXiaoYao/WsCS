## 🚀 如何使用

### 基本对话流程

1. **打开浏览器**: http://localhost:3000
2. **选择工具**: 点击顶部导航 "AI工具箱"
3. **选择模型**: 在左侧边栏选择想要的模型
4. **输入问题**: 在底部输入框输入问题
5. **发送消息**: 按 Enter 或点击发送按钮
6. **查看回复**: AI 回复会显示在对话区域

### 历史记录功能

1. **查看历史**: 左侧边栏自动显示最近 20 条对话
2. **加载对话**: 点击历史记录项，右侧显示完整对话
3. **刷新历史**: 点击历史记录标题旁的刷新按钮
4. **基于历史继续**: 加载历史对话后，可以基于上下文继续提问

### 高级功能

1. **调节随机性**: 使用温度滑块控制 AI 回复的创造性
   - 0.0-0.3: 更确定性、保守的回答
   - 0.7-1.0: 平衡的回答（推荐）
   - 1.5-2.0: 更有创造性、随机的回答

2. **切换模型**: 支持 447+ 种模型
   - GPT 系列（gpt-3.5-turbo, gpt-4 等）
   - Claude 系列
   - Gemini 系列
   - DeepSeek 系列
   - 以及其他第三方模型

3. **对话管理**:
   - 每个新对话自动生成唯一 ID
   - 对话自动保存到数据库
   - 可随时查看、复用历史对话

## ⌨️ 快捷键与手势

### 键盘快捷键

**通用快捷键**:
- `Enter`: 发送消息
- `Shift + Enter`: 换行（不发送）
- `Ctrl + /`: 聚焦到输入框
- `Esc`: 关闭侧边栏（移动端）

**桌面端专属**:
- `Ctrl + L`: 清空对话
- `Ctrl + H`: 打开/关闭历史记录侧边栏
- `↑ / ↓`: 在历史消息中导航（需先聚焦输入框）

### 触摸手势（移动端）

- **左滑**: 打开侧边栏菜单
- **右滑**: 关闭侧边栏菜单
- **点击遮罩**: 关闭侧边栏
- **长按消息**: 复制消息内容
- **双击消息**: 快速复用到输入框

### 鼠标操作（桌面端）

- **滚轮**: 滚动查看历史消息
- `Ctrl + 滚轮`: 缩放页面（浏览器默认功能）
- **右键菜单**: 浏览器默认右键菜单

## 📱 响应式设计

### 断点设置

- **桌面端** (> 1024px): 完整布局
  - 左侧边栏: 300px 固定宽度
  - 右侧对话区域: 自适应剩余空间

- **平板端** (768px - 1024px): 紧凑布局
  - 左侧边栏: 280px 固定宽度
  - 内容区域: 适当缩小边距和字体

- **移动端** (≤ 768px): 移动端优化
  - **侧边栏**: 可滑出的抽屉式菜单
    - 通过左上角按钮控制显示/隐藏
    - 带遮罩层，点击遮罩关闭
    - 宽度 280px，或占满屏幕（≤ 480px）
  - **对话区域**: 全屏显示
    - 缩小边距和字体大小
    - 优化触摸体验
    - 更大的点击区域

- **小屏手机** (≤ 480px): 极致优化
  - 侧边栏: 占满屏幕宽度
  - 消息气泡: 占屏幕宽度 90%
  - 进一步缩小字体和间距

### 移动端特色功能

1. **汉堡菜单按钮**: 左上角显示菜单按钮
2. **抽屉式侧边栏**: 从左侧滑出，带平滑动画
3. **遮罩层**: 显示侧边栏时，主内容区域变暗
4. **触摸优化**: 更大的点击区域，适合手指操作
5. **滑动关闭**: 点击遮罩或向左滑动关闭侧边栏

### 自适应特性

✅ **字体大小**: 根据屏幕尺寸自动调整
✅ **间距**: 小屏幕下减少不必要的空白
✅ **按钮尺寸**: 移动端增大点击区域
✅ **输入框**: 自适应宽度，优化触摸键盘体验
✅ **图片尺寸**: 根据设备像素密度自动调整

## 🔧 技术实现

### 前端技术
- **框架**: Vue 3 + TypeScript
- **UI库**: Element Plus
- **布局**: Flexbox + CSS Grid
- **动画**: CSS Transitions + Transform
- **响应式**: CSS Media Queries + JavaScript Resize Observer

### 后端技术
- **框架**: Node.js + Express + TypeScript
- **数据库**: PostgreSQL
- **ORM**: pg (PostgreSQL Client)
- **实时更新**: WebSocket (预留)

### API 接口
- `GET /api/tools`: 获取可用工具
- `GET /api/tools/models?toolId=xxx`: 获取模型列表
- `POST /api/tools/:id/execute`: 执行工具
- `GET /api/tools/history`: 获取对话历史
- `GET /api/tools/history/stats`: 获取统计信息

## 💡 使用技巧与最佳实践

### 对话技巧

1. **清晰的问题描述**
   - ✅ 好例子: "请用Python写一个快速排序算法，并添加详细注释"
   - ❌ 坏例子: "排序算法"

2. **提供上下文**
   - 在提问前说明背景和需求
   - 提供相关的代码片段或错误信息
   - 说明期望的输出格式

3. **使用系统消息**（高级）
   - 在对话开始时设置AI的角色
   - 例如: "你是一个资深的Python开发专家"

4. **温度参数调节**
   - **0.0-0.3**: 事实性问题、数学计算、代码生成
   - **0.7-1.0**: 通用对话、创意写作、头脑风暴
   - **1.5-2.0**: 诗歌创作、艺术创作、探索性思维

### 模型选择指南

| 使用场景 | 推荐模型 | 原因 |
|---------|---------|------|
| 日常对话 | gpt-3.5-turbo | 快速、成本低 |
| 复杂推理 | gpt-4 | 更强大的推理能力 |
| 代码生成 | CodeLlama, StarCoder | 专门优化 |
| 中文对话 | 文心一言、通义千问 | 中文理解更好 |
| 创意写作 | Claude-3 | 更自然的文笔 |
| 多模态 | GPT-4V | 支持图片输入 |

### 效率提升技巧

1. **快捷键**: 熟练使用快捷键可以大幅提升效率
2. **历史复用**: 基于历史对话继续，保持上下文连贯
3. **批量提问**: 将相关问题一起提问，减少来回次数
4. **模板化**: 对常见任务创建提问模板
5. **参数预设**: 保存常用的温度、模型配置

### 注意事项

⚠️ **隐私安全**:
- 不要在对话中输入敏感信息（密码、密钥等）
- 重要数据建议本地处理
- 定期清理不需要的历史记录

⚠️ **API 使用**:
- 注意 API 调用频率限制
- 监控 Token 使用量
- 合理设置 max_tokens 避免意外高消费

⚠️ **内容准确性**:
- AI 回答可能包含错误信息
- 重要决策需要人工验证
- 代码需要测试后再使用
